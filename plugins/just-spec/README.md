# Just Spec plugin

This directory is the installable Claude Code plugin exposed by the repository marketplace.

Command:

- `/just-spec:spec <request>` — dynamically resolve material ambiguity, persist a lean, observable behavioral contract, and end with the `/goal` line that runs it. It has no fixed question limit and splits only on semantic capability boundaries.

Execution is Claude Code's own `/goal`. This plugin has no implementation command: the spec carries the rules of the run, and the evaluator judges the run from what it reports.

Core testing rule:

> Tests come from the contract, not the implementation.

Project documentation: https://github.com/Basio0916/just-spec
