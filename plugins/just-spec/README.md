# Just Spec plugin

This directory is the installable Claude Code plugin exposed by the repository marketplace.

Commands:

- `/just-spec:spec <request>` — dynamically resolve material ambiguity and persist a lean, observable behavioral contract. It has no fixed question limit and splits only on semantic capability boundaries.
- `/just-spec:build <spec>` — derive implementation and verification from the same contract, keep planning ephemeral, allow flexible test timing, and report AC evidence.

Core testing rule:

> Tests come from the contract, not the implementation.

Project documentation: https://github.com/Basio0916/just-spec
